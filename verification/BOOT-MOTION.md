## 实现范围与限制

原生 DOM/SVG 重建，未将视频嵌入产品。离散切换按原片帧编号确定；`boot-tracks.ts`、`boot-logo-tracks.ts` 与 `boot-orbit-tracks.ts` 保留上游非线性轨迹，正放、倒放和跳帧由同一状态函数计算。启动用共享标志的连续轮廓绘制和切除，不进行整组淡出。三行品牌独立运动，品牌覆盖、姓名与公司名称继续读取 SiteConfig。曲线、光晕、背景抽象线条和字体栅格化仍与原片有差异，不宣称逐像素一致。

## 验证

- `npm run build`：通过 TypeScript 与生产构建。保留原有 bundle 大小提示。
- `reference/boot-check.html`：本次 30 项检查通过。覆盖关键帧、非线性轨迹、连续轮廓、卫星点、灰闪遮罩、实际页面正反跳帧、无 CSS 循环动画、跳过后的品牌恢复及阵列衔接。
- `reference/boot-review.html`：保留原片与真实页面同步入口，支持逐帧和 1× / 0.5× / 0.25×。需要自行提供本地参考视频；本次通过浏览器核对真实应用状态。
- `npm run check:boot`：两个生产站点各检查九个参考阶段、配置品牌、英文案例字幕及悬停、点击、抽取、返回。完整结果见 [UPSTREAM-SYNC.md](UPSTREAM-SYNC.md)。
- 首次播放延后 600ms，以便加载遮罩完全淡出后再输入第一个字；减少动态效果偏好继续直接进入档案。

在仓库根目录运行 `reference/extract-boot.py` 可从本地 MP4 重新提取参考帧，需要 Python、OpenCV 和 Pillow；视频和 JPG 均被 Git 忽略。
